    **Query parameters** (параметры строки запроса) — это часть URL-адреса, используемая для передачи дополнительных данных серверу (фильтрация, сортировка, поиск). Они начинаются после знака вопроса `?` и представляют собой пары «ключ=значение», разделенные амперсандом `&`, например: `?category=books&sort=asc`.
