# Atomicity

!!! note ""
    **Атомарность** — это свойство операции или транзакции в программировании и базах данных, гарантирующее их неделимость. Атомарная операция выполняется либо целиком (успешно), либо не выполняется вовсе, исключая промежуточные состояния. Она обеспечивает целостность данных, предотвращая частичное применение изменений при сбоях или параллельных процессах.
