    **Доменные имена** — это удобочитаемые интернет-адреса, которые преобразуются в IP-адреса для идентификации компьютера. Они состоят из домена второго уровня («example») и домена верхнего уровня («.com»). Управляются регистраторами, обеспечивая удобную навигацию по сайту вместо числовых IP-адресов.

![Domain names](https://love2dev.com/img/domain-name-structure-diagram-1956x936.png)

## Иерархия уровней

Доменные имена читаются справа налево, где каждая часть, разделенная точкой, представляет собой определенный уровень иерархии в системе DNS.

- Нулевой уровень `Root`: корневой домен, представленный невидимой точкой в конце адреса.
- Первый уровень `TLD`: домены верхнего уровня, такие как `.com`, `.org` или национальные `.ru`, `.ua`.
- Второй уровень `SLD`: основное имя сайта (например, example в example.com), которое регистрируется пользователем.
- Третий уровень `Поддомен`: дополнительные разделы сайта, такие как blog.example.com или docs.google.com.

## Принцип работы DNS

<span class="badge">DNS (Domain Name System)</span> работает как «телефонная книга» интернета, сопоставляя буквенные адреса с цифровыми IP-адресами серверов.  

Когда вы вводите адрес в браузере, рекурсивный DNS-сервер опрашивает цепочку серверов (корневые → сервера TLD → авторитетные сервера домена), пока не найдет нужный IP.  

Этот процесс называется «разрешением имен» (resolving) и обычно занимает доли секунды благодаря кэшированию данных на разных уровнях.

## Типы доменов верхнего уровня

Все TLD делятся на несколько основных категорий в зависимости от их назначения и географической привязки:

| Тип	| Описание | Примеры |
| ----- | -------- | ------- |
| gTLD | Общие домены общего пользования (generic) | `.com, .net, .info, .biz` |
| ccTLD | Национальные домены стран (country code) | `.ru, .de, .uk, .us, .uz` |
| sTLD | Спонсируемые домены для узких групп (sponsored) | `.gov, .edu, .mil, .museum` | 
| newTLD | Новые тематические домены (new generic) | `.tech, .online, .app, .club` |
