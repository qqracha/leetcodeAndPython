# Rest API

!!! note ""
    REST API (Representational State Transfer Application Programming Interface) — это архитектурный стиль взаимодействия между системами (клиентом и сервером) через протокол HTTP. Он обеспечивает стандартизированный способ обмена данными, используя понятные URL-адреса и стандартные методы (GET, POST, PUT, DELETE), что делает его гибким и масштабируемым решением для веб-сервисов.
