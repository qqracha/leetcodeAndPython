## Определение
!!! info ""
    **Хеш-таблица** (Hash Table) — это структура данных, которая хранит пары **ключ → значение** 
    и обеспечивает быстрый доступ к элементам по ключу за счёт вычисления хеша и индекса в массиве.


## Как она работает
   <span class="badge">Хеш-функция</span> берёт ключ (например, `"apple"`) и превращает его в число, по которому выбирается индекс внутри массива бакетов (ячеек).
   
Схема:

1. Вычисляем <span class="badge">hash(key)</span>
2. Превращаем хеш в индекс массива: <span class="badge">index = hash(key) % size</span>
3. В ячейке <span class="badge">index</span> храним (или находим) значение

   Если разные ключи дали один и тот же индекс, возникает <span class="badge">collision</span> (коллизия), и её нужно разрешать (иначе непонятно, где хранить данные).

## Коллизии
<span class="badge">Коллизия</span> — ситуация, когда разные ключи попадают в один и тот же индекс.  

Основные способы разрешения коллизий:  

- <span class="badge">Chaining</span> (цепочки): в одной ячейке хранится список/цепочка элементов.
- <span class="badge">Open Addressing</span> (открытая адресация): при коллизии ищется другая свободная ячейка по правилу «пробирования».  

| Способ                                     | Идея	                                                     | Пример                      |
|--------------------------------------------|-----------------------------------------------------------|-----------------------------|
| <span class="badge">Chaining</span>        | 	В бакете хранится коллекция элементов                    | 	`bucket[i] = [k1, k2, k3]` |
| <span class="badge">Open Addressing</span> | 	Элемент кладётся в следующую подходящую свободную ячейку | 	`i -> i+1 -> i+2 ... `     |

## Когда используют
   <span class="badge">Hash Table</span> выбирают, когда нужен быстрый доступ к данным по ключу: поиск, вставка и удаление обычно стремятся к O(1) в среднем.  
   Она хорошо подходит для кэшей, частотных словарей, индексов, быстрых проверок «есть ли элемент».

   Типичный кейс: «по id получить объект» или «посчитать частоты слов».

## Хеш-таблица в Python
В Python основная хеш-структура — это <span class="badge">dict</span> (словарь): он хранит пары ключ–значение и реализует быстрый доступ по ключу.

Важно про ключи:  

- Ключ должен быть **хешируемым** (hashable), то есть иметь стабильный `__hash__()` и корректный `__eq__()`.  
- Обычно ключи — это `str`, `int`, `tuple` (если внутри тоже hashable), `frozenset`.  

## Пример
### Частоты слов
```python
    text = "spam spam eggs spam"
    freq = {}
    
    for word in text.split():
        freq[word] = freq.get(word, 0) + 1
    
    print(freq) # {'spam': 3, 'eggs': 1}
    ### Свой ключ (важно: __hash__ + __eq__)
    class UserId:
        def __init__(self, value: int):
            self.value = value
        def __hash__(self):
            return hash(self.value)
        def __eq__(self, other):
            return isinstance(other, UserId) and self.value == other.value
        
    users = {}
    users[UserId(1)] = "Alice"
    users[UserId(2)] = "Bob"
    
    print(users[UserId(1)]) # Alice
```
## Ключевые мысли
- Хеш-таблица — это «массив + хеш-функция», который даёт быстрый доступ по ключу.
- O(1) работает **в среднем**, потому что эффективность зависит от коллизий и размера таблицы.
- В Python словари — базовый инструмент для задач «по ключу быстро найти значение».
