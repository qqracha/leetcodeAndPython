# Telethon

    !!! note ""
    Telethon — это популярная асинхронная библиотека Python, предназначенная для взаимодействия с Telegram API (MTProto). В отличие от обычных ботов, она позволяет создавать клиентские приложения (юзерботы), действующие от имени обычного пользователя, что дает возможность парсить сообщения, управлять каналами и автоматизировать действия без ограничений Bot API.
