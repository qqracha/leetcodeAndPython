Первая строка комментария к коммиту будет иметь вид:
```python
    feat: добавить колебание шапки
    ^ — ^ ^ — — — — — — ^
    | |
    | +-> Резюме в настоящем времени.
    |
    + - - - -> Type: chore, docs, feat, fix, refactor, style или test.
```

Где <type> может быть одним из следующих:

<span class="badge">feat:</span> - новая фича для пользователя, а не, например, новая функция для скрипта сборки.

<span class="badge">fix:</span> - исправление ошибки для пользователей, а не исправление скрипта сборки.

<span class="badge">docs:</span> - изменения в документации.

<span class="badge">style:</span> - форматирование, настройка стиля; без изменения производственного кода.

<span class="badge">refactor:</span> - рефакторинг производственного кода, например, переименование переменной.

<span class="badge">test:</span> - добавление недостающих тестов, рефакторинг тестов; без изменения производственного кода.

<span class="badge">chore:</span> - обновление рутинных задач и т.д., без изменения производственного кода.
